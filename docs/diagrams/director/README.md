# Campus Director Diagrams Suite

> **Role:** `DIRECTOR` (Campus Director & Executive Signatory)  
> **System:** MinSU DocTrack

---

## 1. Role Scope & Responsibilities

The Campus Director provides executive oversight for the Tulong Dunong Program across all MinSU campuses. The Director inspects submitted Annexes 1 through 10, executes official endorsements (approvals), returns documents with revision instructions, and monitors executive velocity analytics.
