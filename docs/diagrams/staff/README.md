# Staff Coordinator Diagrams Suite

> **Role:** `STAFF` (Staff Coordinator & Annex Operations)  
> **System:** MinSU DocTrack

---

## 1. Role Scope & Responsibilities

The Staff Coordinator is the primary operational user in MinSU DocTrack. Staff members create and edit Annexes 1 through 10, configure dynamic TDP applicant calls, review student submissions, compile accepted applicants into Annex 1 rosters, upload wet-ink signed scans, and record external transmittals in the Outgoing Registry.
